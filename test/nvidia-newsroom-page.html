NVIDIA Newsroom publishes a research update

November 23, 2026

The research team published an update on its most recent experiments. The report explains how the team chose the measurements, how it set up the test environment, and which results it could reproduce across different machines and software versions.

The team first tested a small dataset to check that each part of the process behaved as expected. It repeated each run several times, tracked the differences in results, and made notes about changes in the environment that might explain those differences.

The larger experiment took place after these initial checks. Engineers compared the new results with the original measurements and recorded missing data separately so readers could distinguish an incomplete run from a valid result.

The public report also lists the cases that the experiment does not cover. These include machines with different memory limits, workloads that run for longer periods, and applications that share a machine with unrelated background work.

The research team will publish a follow-up after it finishes the next series of experiments. Readers can use the methods described in the report to repeat the current tests and compare their results with the published measurements.
